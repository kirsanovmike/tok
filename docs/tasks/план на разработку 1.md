## Финальная постановка

**Что делаем.** «Ток» — компонент AI-ассистента для энергосбытовой платформы «Трансфера»: выезжающая справа панель с чатом, отвечающая на вопросы по данным договоров.

**Как поставляется.** Отдельное Vue CLI приложение с демо-страницей-хостом. Весь код Тока изолирован в одной папке и переносится в Трансферу копированием.

### Зафиксированные решения

| Тема | Решение |
|---|---|
| Стек | Vue 2.6.14 (Options API), Vuetify 2.6.3, Vuex 3, SCSS, amCharts 4.10.20, axios 0.21.4, date-fns, portal-vue |
| Дизайн-система | `@tne-ui/*` **не используем** (недоступна: npm 404). Строим на Vuetify + SCSS по макетам |
| Демо-хост | Упрощённый дашборд Трансферы: шапка, табы, 3–4 карточки, футер. Обе темы |
| Тема | Расширяем обе палитры (`light` и `dark`) симметрично + градиент. **Ни одного hex в компонентах** |
| Контракт | `contents[]` — массив, дискриминатор — строковое поле `type`, в ответе допустимо несколько блоков |
| `reply.text` | Plain text. Markdown **не** рендерим, зависимость на `marked`/`markdown-it` не берём |
| Скоуп ответов | Данные по договорам: тариф (`cost`), объём (`volume`), стоимость (`price`) |
| Чипы-подсказки | Пишем под реальный скоуп. Чип — call to action, дальше ассистент уточняет параметры |
| Графики | Линейный (area) по умолчанию + переключение на другие типы из референсов |
| Выгрузка в Excel | **Вне v1.** Слот в разметке предусмотреть |
| История | `localStorage`, версионированный ключ, **TTL сообщения — 1 месяц**, кнопка очистки беседы |
| Под ответом | Копирование — да. «Источник» — реализован, но скрыт. Закладка — нет |
| Голос | `MediaRecorder` → MP3 → `multipart/form-data`. В демо — мок, ответ `{ "text": "" }` |
| Тесты | Только в демо-проекте, **вне переносимой папки**, чтобы перенос был чистым |
| Вне скоупа | Строка «не нашли ответа, напишите в службу поддержки» |

### Решения, принятые исполнителем

- **Ширина панели:** ≥960px — 480px; 600–960px — 60vw, но не менее 420px; <600px — 100vw.
- **Скругления:** левые углы скруглены, **правый край строго прямой** («шторка»). На 100vw скругления снимаются.
- **Звёздочки загрузки:** вращение **вокруг оси Z** (в плоскости экрана), `prefers-reduced-motion` уважаем.
- **Фразы загрузки (8, дата-агностичные):** «Думаю…», «Шуршу по данным Трансферы…», «Нужно ещё немного подумать…», «Собираю картинку…», «Раскладываю по полочкам…», «Сверяюсь с цифрами…», «Ещё пара секунд…», «Почти готово…».
- **Копирование:** иконка под ответом ассистента, копирует текстовое представление всего ответа, обратная связь «Скопировано» на 2 c.
- **Шаг подтверждения:** та же лента, но акцентная левая граница и две кнопки — «Подтвердить» / «Отменить».
- **MP3:** `@ffmpeg/ffmpeg` + **однопоточный** `@ffmpeg/core@0.12.10`, файлы core в `public/`, ленивая загрузка при первой записи.
- **Токены Тока — плоские цвета верхнего уровня** (`tok-surface`, а не `tok: { surface }`): Vuetify 2 внутри вложенной группы оставляет только `base`, `lighten*`, `darken*`. В CSS доступны как `--v-tok-surface-base` через `tok-color()`.
- **Node 25:** webpack 4 требует `NODE_OPTIONS=--openssl-legacy-provider` — прописано в npm-скриптах через `cross-env`.
- **Jest поднят до 26** через `overrides`: пресет из `@vue/cli-plugin-unit-jest@4.5.13` тянет `vue-jest@3` → нативный `deasync`, который не собирается на Node 25. Тесты в Трансферу не переносятся, на рантайм-зависимости это не влияет.
- **`@mdi/font`** добавлен только ради демо-хоста; в `src/tok/` иконки будут собственными SVG (в Трансфере эту роль играет `@tne-ui/sprites`).
- **Стор:** Ток заводит **собственный** экземпляр Vuex-стора и раздаёт его через `provide`/`inject`, а не регистрирует модуль в сторе хоста — ADR-0006. Перенос остаётся копированием папки.
- **Пузырь пользователя — слева**, а не справа: так на обоих макетах с перепиской. Исходная формулировка задачи фазы 5 исправлена.
- **Кнопка отправки отсутствует** до появления текста, а не показывается неактивной — так в макете пустого состояния.
- **Прозрачность оверлея** задаётся `opacity`, а не `rgba()`: alpha-канал через токен темы не пронести, парсер Vuetify 2 понимает только 6-значный hex.
- **Фикстуры на стенде** открываются параметром `?tokFixture=<id>` — единственный способ показать любую комбинацию контракта, не собирая отдельную страницу-каталог.
- **От Vuetify Ток берёт только тему:** ни одного `v-*`-компонента внутри `src/tok/` нет, панель собрана на нативных элементах. Слой замены на `@tne-ui` свёлся к иконкам.
- **Копируется весь ответ, а не `reply.text`:** у каждого типа блока есть текстовая форма (`utils/answerText.js`), таблица уходит в буфер колонками через табуляцию и вставляется прямо в Excel. Блок, который не показан, не копируется.
- **Форматирование чисел — единое и зафиксированное:** локаль `ru-RU` прописана в коде, а не берётся из браузера, иначе таблица меняла бы вид от настроек ОС.
- **График — асинхронный чанк:** amCharts около 700 КБ, и он не должен ехать в основном бандле ради тех, кто ни разу не спросил про динамику.
- **Цвета графиков** достаются из **вычисленных** CSS-переменных в рантайме (amCharts не понимает `var(--v-…)`), с запасным источником в `theme/tokens.js`. Правило «hex только в токенах» не нарушено.
- **Легенда только при нескольких рядах:** у одного ряда её роль играет подпись оси значений.
- **ffmpeg подключается тегом `<script>` из `public/`, а не импортом** — ADR-0007. Причина найдена при реализации: webpack 4 принимает UMD как формат, но не понимает приватные поля классов внутри него.
- **Мок расшифровки по умолчанию отвечает осмысленной фразой,** а не `{"text": ""}`, как было записано в постановке: иначе сценарий «запись → текст в поле» на стенде показать нечем. Пустой ответ воспроизводится флагом `mockTranscript: ''`.
- **Подтверждение очистки — полосой внутри панели,** а не системным `confirm()`: модальное окно браузера блокирует страницу хоста и в части окружений подавляется.
- **Восстановленный из хранилища шаг подтверждения считается пройденным:** нажать «Подтвердить» по вчерашней беседе — почти наверняка не то, чего ждёт человек.
- **Переполнение квоты `localStorage` не теряет беседу:** сохраняется хвост из последних 20 сообщений.
- **Сброс хоста перекрашивал кнопки Тока — миксин `tok-button-color()`.** И Vuetify, и normalize объявляют `button, [type="button"], … { color: inherit }`. Специфичность такого селектора — (0,1,0), **ровно как у одиночного класса**, а подключается он позже стилей компонентов, поэтому при равной специфичности побеждает. Результат: «Подтвердить» получала цвет `text` вместо `text-inverse` — 2,59:1 в тёмной теме, и то же самое молча происходило с иконочными кнопками. Лечится не подкруткой цвета, а специфичностью: миксин добавляет префикс `.tok-root` и поднимает правило до (0,2,0). Кнопки графика уцелели случайно — их CSS едет отдельным чанком и подключается позже сброса; полагаться на порядок загрузки чанков нельзя, поэтому миксин применён и к ним. **Это в первую очередь про перенос:** в Трансфере сбросы свои, и правило «цвет кнопки задаётся селектором из двух классов» защищает от них всех.
- **`text-muted` и `accent` в светлой теме подняты до AA.** `#909090` давал 2,85:1 на `surface-muted` — им набраны заголовки колонок таблицы, подпись `stat`, подписи осей и плейсхолдер, то есть содержательный текст, а не декор; стало `#6B6B6B` (4,76:1). `accent` `#3879F6` не проходил **в обе стороны** — 4,03:1 и белым по нему, и им на белом; стало `#2F6FE0` (4,73:1). Тёмная тема обе проверки проходила изначально.
- **`danger` разведён по темам.** Статусные цвета были одинаковыми в обеих палитрах — и именно поэтому `#E43636` не проходил AA нигде: 4,30:1 на светлой поверхности и 4,09:1 на тёмной. Это цвет **текста** сообщения об ошибке, а не точки-индикатора. Стало `#C62828` в светлой и `#FF6B6B` в тёмной — красный, как и весь остальной текст, инвертируется вместе с палитрой.
- **У поля ввода не было индикатора фокуса:** `outline: none` без замены, при том что у всех остальных контролов есть `:focus-visible`. Индикатор повешен на «таблетку» `&__field` через `:focus-within`, а не на голый `<input>`: обводка вокруг текстового бокса шла бы прямоугольником внутри скруглённого поля. Именно `:focus-within`, а не `:focus-visible`, — у поля ввода фокус с клавиатуры и мышью равнозначен, человек в обоих случаях должен видеть, куда печатает.
- **Блокировка скролла хоста не работала в приложении на Vuetify.** `lockPageScroll()` ставил `overflow: hidden` на `<body>`, но переполнение `<body>` наследуется вьюпортом **только пока у `<html>` оно `visible`**, а Vuetify в своём сбросе объявляет `html { overflow-y: scroll }`. Страница под открытой панелью спокойно прокручивалась колесом. Теперь `overflow` глушится на обоих элементах, а при закрытии возвращается **прежнее inline-значение**, а не пустая строка: хост мог держать своё. **Инструмент проверки тоже был неверен:** первым заходом бралось `window.scrollBy()`, а оно по определению разрешено при `overflow: hidden` — дефект показало только живое событие `mouseWheel`. Та же природа, что и у истории с кнопками: в обоих случаях виноват не Ток, а его молчаливое соседство со сбросами хоста, и в Трансфере повторилось бы один в один.
- **Контраст закреплён юнит-тестом** (`tests/unit/theme-contrast.spec.js`, 23 проверки). Браузерная проверка живёт один прогон, а токены правят потом. Пары «текст на фоне» выписаны руками: связь «этот цвет лежит на этом фоне» known только из компонентов, и вывод её эвристикой сделал бы тест зелёным на неверных данных.
