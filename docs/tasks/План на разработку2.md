## Global Constraints

Действуют на все задачи и повторяются здесь, потому что исполнитель задачи видит только свой раздел.

- **Ни одного hex-литерала вне `theme/tokens.js`.** Цвета в компонентах — только через `tok-color(<токен>)`. `linear-gradient(` допустим только в `styles/_tokens.scss`. Это проверяет `tests/unit/tok-boundary.spec.js`.
- **Наборы ключей `light` и `dark` в `tokens.js` обязаны совпадать** — `tests/unit/theme-parity.spec.js`.
- **Цвет любого `<button>` — миксином `@include tok-button-color(<токен>)`**, а не `color:` напрямую: сбросы хоста перебивают одиночный класс.
- **Vue 2 Options API.** Никакого Composition API, никаких `<script setup>`.
- **amCharts именно 4.10.20.** API пятой версии неприменим целиком.
- **Отступы и скругления — из SCSS-переменных** `$tok-space-*`, `$tok-radius-*` (`styles/_tokens.scss`), которые подключаются во все SFC автоматически через `vue.config.js`.
- **Стили не scoped, именование BEM с префиксом `tok-`.**
- **Внутри папки Тока — только относительные импорты.** Ни одного `@/…`: папка копируется в чужой проект, где алиаса `@` может не быть вовсе. Проверка добавляется в задаче 7.
- **Уважать `prefers-reduced-motion`** во всех анимациях.
- **UI-копия на русском.**
- Команды: `npm run test:unit`, `npm run lint`, `npm run lint:style`, `npm run serve`.
  Один файл тестов: `npx vue-cli-service test:unit --testPathPattern <path>`; один тест: `-t "<имя>"`.
  Все скрипты обёрнуты в `cross-env NODE_OPTIONS=--openssl-legacy-provider` — вызывать только через `npm run` / `npx vue-cli-service`.
- **jsdom не считает layout.** Пиксели, тени, отступы и вращение автотестами не проверяются — у каждой такой задачи есть блок «Визуальная проверка» с точным списком того, что смотреть глазами на `npm run serve`.

### Задача 1: Выравнивание внутри поля ввода

Закрывает пункты **1** и **2** постановки.

**Файлы:** изменить `src/tok/components/TokComposer.vue` (только блок `<style>`), `tests/unit/tok-composer.spec.js`.

**Диагноз.** `.tok-composer__field` выровнен по `align-items: flex-end` (`TokComposer.vue:324`) — это правильно для обычного состояния: поле растёт вверх, кнопки остаются внизу. Но это же правило действует и в двух местах, где оно вредит:

1. **Полоса записи** (`&--voice`): надпись «Идёт запись · 0:07» — обычный `<p>` высотой в одну строку (~20px) между двумя кнопками по 36px. При `flex-end` она прижимается к низу и оказывается ниже центров иконок — это и есть «уехала вниз».
2. **Крестик очистки**: при выросшем до нескольких строк текстовом поле кнопка 32×32 прижата к низу, то есть к нижнему краю фона, а не к его середине.

**Решение.** Полосе записи — своё выравнивание по центру (у неё поле не растёт, там нечего прижимать книзу). Крестику — `align-self: center`: он центрируется по высоте контента поля независимо от того, на сколько строк вырос текст. Вертикальные отступы поля равны (`padding: 6px … 6px`), поэтому центр контента — это и есть центр фона.

### Задача 2: Кнопка остановки — сплошной белый квадрат

```js
// Демо-стенд отвечает нарочито медленно: за 6 секунд успевают смениться
// три фразы лоадера и разглядеться вращение звёздочки. Боевая задержка мока —
// 700 мс (DEFAULT_CONFIG). Перебивается адресной строкой: `?tokDelay=700`.
const DEMO_MOCK_DELAY_MS = 6000;

export function readDemoMockDelay() {
  try {
    const raw = new URLSearchParams(window.location.search).get('tokDelay');
    const parsed = Number(raw);
    return raw !== null && Number.isFinite(parsed) && parsed >= 0 ? parsed : DEMO_MOCK_DELAY_MS;
  } catch (e) {
    return DEMO_MOCK_DELAY_MS;
  }
}
```

Конфигурация читается Током один раз в `beforeCreate`, поэтому объект обязан быть готов до первого рендера.

**Решение.** Две правки, обе служат одному: ожидание должно ощущаться движением вперёд, а не набором случайных реплик.

1. **Набор** переписывается под просьбу заказчика: «ищу по Трансфере», «анализирую данные», «ещё чуть-чуть». Предметные сущности (договор, тариф, объём, стоимость, счёт, киловатт) по-прежнему запрещены — фраза про них соврёт на половине вопросов.

Заменить содержимое `src/tok/utils/phraseRotator.js`:

```js
/**
 * Выбор следующей фразы загрузки.
 *
 * Фразы идут по порядку — это сценарий ожидания (см. `constants/loadingPhrases.js`).
 * Дойдя до конца, ротатор возвращается не в начало, а к последним `tailSize`
 * фразам: «Почти готово…» → «Ещё чуть-чуть…» → «Почти готово…». Случайный
 * выбор здесь был раньше и отменён — он позволял вернуться от «Почти готово…»
 * к «Думаю…», то есть визуально откатить прогресс.
 *
 * Требование «одна и та же фраза не выпадает дважды подряд» выполняется по
 * построению: следующий индекс всегда отличается от текущего.
 */
export function nextPhraseIndex(currentIndex, total, tailSize = 2) {
  if (total <= 1) return 0;

  const next = currentIndex + 1;
  if (next < total) return next;

  // Сценарий доигран — крутим хвост. Хвост не может быть длиннее списка
  // и обязан состоять хотя бы из двух фраз, иначе подпись замрёт.
  const tail = Math.min(Math.max(tailSize, 2), total);
  return total - tail;
}

export default nextPhraseIndex;
```

```js
// Высота шкалы масштаба. Дефолтный `am4core.Scrollbar` занимает около 35px —
// это треть холста в панели 480px, ради которых его в прошлый раз и прятали
// за порогом по количеству точек. 10px помещаются всегда.
const SCROLLBAR_HEIGHT = 10;
const SCROLLBAR_GRIP_WIDTH = 14;

/**
 * Тонкая шкала масштаба под осью категорий.
 *
 * Дефолтные хваты — «гантели» с иконкой-стрелками — выше самой полосы и ломают
 * её линию. Иконки убираем, но сами хваты оставляем видимой ширины: это
 * единственная область, за которую шкалу тянут краем, и без неё зум остаётся
 * только колесом и курсором.
 */
function createZoomScrollbar(palette) {
  const scrollbar = new am4core.Scrollbar();

  scrollbar.height = SCROLLBAR_HEIGHT;
  scrollbar.minHeight = SCROLLBAR_HEIGHT;
  scrollbar.marginTop = 10;
  scrollbar.marginBottom = 0;

  scrollbar.background.fill = am4core.color(palette.grid);
  scrollbar.background.fillOpacity = 1;
  scrollbar.background.cornerRadius(
    SCROLLBAR_HEIGHT / 2,
    SCROLLBAR_HEIGHT / 2,
    SCROLLBAR_HEIGHT / 2,
    SCROLLBAR_HEIGHT / 2,
  );

  scrollbar.thumb.background.fill = am4core.color(palette.textMuted);
  scrollbar.thumb.background.fillOpacity = 0.45;
  scrollbar.thumb.background.cornerRadius(
    SCROLLBAR_HEIGHT / 2,
    SCROLLBAR_HEIGHT / 2,
    SCROLLBAR_HEIGHT / 2,
    SCROLLBAR_HEIGHT / 2,
  );

  // Без этого amCharts перекрашивает ползунок в свой дефолтный синий при наведении
  // и нажатии — мимо палитры темы.
  ['hover', 'down'].forEach((key) => {
    const state = scrollbar.thumb.background.states.getKey(key);
    if (state) {
      state.properties.fill = am4core.color(palette.textMuted);
      state.properties.fillOpacity = 0.7;
    }
  });

  [scrollbar.startGrip, scrollbar.endGrip].forEach((grip) => {
    grip.icon.disabled = true;
    grip.width = SCROLLBAR_GRIP_WIDTH;
    grip.height = SCROLLBAR_HEIGHT;
    grip.background.fill = am4core.color(palette.textMuted);
    grip.background.fillOpacity = 0.7;
    grip.background.strokeOpacity = 0;
    ['hover', 'down'].forEach((key) => {
      const state = grip.background.states.getKey(key);
      if (state) {
        state.properties.fill = am4core.color(palette.textMuted);
        state.properties.fillOpacity = 1;
      }
    });
  });

  return scrollbar;
}
```

## Открытые вопросы к заказчику

Не блокируют работу — исполнитель действует по умолчанию, указанному ниже, и выносит вопрос в отчёт.

1. **Логотип amCharts.** Снимается только при коммерческой лицензии. По умолчанию: механизм реализован, флаг поднят **в демо-стенде**, в `DEFAULT_CONFIG` — `false`. Нужно подтверждение лицензии, чтобы поднять его в Трансфере.
2. **Задержка мока 6 с.** Это отладочная настройка демо-стенда. По умолчанию остаётся в стенде с возможностью перебить адресной строкой (`?tokDelay=700`). Если стенд показывают заказчику как «почти продукт», задержку стоит вернуть к 700 мс — сказать одним сообщением.
3. **Крестик очистки по центру при многострочном вводе.** Выполнено буквально по постановке: крестик центрируется, микрофон и отправка остаются внизу. Если это будет выглядеть разнобоем — альтернатива в одну строку: `align-self: center` у всех трёх кнопок.
4. **Дубликаты файлов в корне репозитория** (`package 2.json`, `vue.config 2.js`, `src/main 2.js`, `tests/unit 2/`, `docs/Задача 2.txt`) — похоже на артефакты синхронизации iCloud.
