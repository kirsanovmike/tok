**Постановка:** `docs/tasks/доработки1.md` — семь задач, требования и критерии приёмки. Этот файл отвечает на вопрос «как», постановка — на вопрос «что». **Расхождение между ними — дефект этого файла.**

**Цель.** Облегчить тени и оверлей, уменьшить точку входа до 54×54, уплотнить таблицу, сделать фокус ввода деликатным, превратить однострочный `input` в авто-растущее поле как в ChatGPT/Perplexity, заменить плашку подтверждения удаления на меню под иконкой, починить читаемость графика.

**Стек.** Vue 2.6.14 (Options API), Vuetify 2.6.3, SCSS, amCharts 4.10.20, Jest + @vue/test-utils 1.x.

## Global Constraints

Действуют на все задачи, повторяются здесь, потому что исполнитель видит только свою задачу.

- **Ни одного hex-литерала вне `src/tok/theme/tokens.js`.** Цвета в компонентах — только через `tok-color(<токен>)` (см. `src/tok/styles/_tokens.scss`). `linear-gradient(` допустим только в `_tokens.scss`.
- **Наборы ключей `light` и `dark` в `tokens.js` обязаны совпадать** — это проверяет `tests/unit/theme-parity.spec.js`.
- **Цвет любого `<button>` задаётся миксином `@include tok-button-color(<токен>)`,** а не `color:` напрямую: сбросы хоста перебивают одиночный класс.
- **Vue 2 Options API.** Никакого Composition API, никаких `<script setup>`.
- **amCharts именно 4.10.20.** API пятой версии не применим.
- **Отступы и скругления — из SCSS-переменных** `$tok-space-*`, `$tok-radius-*` (`src/tok/styles/_tokens.scss`), которые подключаются ко всем SFC автоматически через `vue.config.js`.
- **Стили не scoped.** Именование строго BEM с префиксом `tok-`.
- **Уважать `prefers-reduced-motion`** во всех новых анимациях (образец — блок в конце `TokEntryButton.vue`).
- **UI-копия на русском.**
- Команды: `npm run test:unit`, `npm run lint`, `npm run lint:style`, `npm run serve`.
  Один файл тестов: `npx vue-cli-service test:unit --testPathPattern <path>`; один тест: `-t "<имя>"`.
  Все скрипты обёрнуты в `cross-env NODE_OPTIONS=--openssl-legacy-provider` — вызывать только через `npm run` / `npx vue-cli-service`.
- **jsdom не считает layout.** Пиксельные размеры, тени, отступы автотестами не проверяются — по каждой такой задаче есть блок «Визуальная проверка» с точным списком того, что посмотреть глазами. Это соглашение проекта (ср. шапку `tests/unit/tok-charts.spec.js`).

### Задача 3: Деликатный фокус поля ввода

Закрывает пункт 4 постановки.

**Файлы:**
- Изменить: `src/tok/components/TokComposer.vue:295-309` (блок `&:focus-within`)

**Интерфейсы:**
- Потребляет: ничего.
- Отдаёт: изменённый вид `.tok-composer__field:focus-within`. Задача 4 правит тот же блок стилей, но другие объявления (`padding`, `align-items`) — конфликта нет, но задачи выполнять последовательно.

**Решение.** Рамка поля — нетекстовый элемент интерфейса, для него действует WCAG 1.4.11: контраст к соседнему цвету ≥ 3:1. Токен `tok-accent` (`#2F6FE0`) даёт 4,73:1 на белом, то есть **1px акцентной рамки достаточно** и по норме, и визуально. Крикливой была не рамка, а `outline: 2px` поверх неё. Её убираем, добавляя вместо неё еле заметное кольцо из `tok-accent-soft` (`#E9F2FF` / `#1F3B65`).

- [ ] **Шаг 1: Заменить индикатор фокуса**

В `src/tok/components/TokComposer.vue` заменить блок `&:focus-within` внутри `&__field` целиком, вместе с комментарием над ним:

```scss
    // Фокус приходит на текстовое поле, а видимая «таблетка» — это контейнер вокруг
    // него. Поэтому индикатор рисуется на родителе: обводка вокруг голого текстового
    // бокса шла бы прямоугольником внутри скруглённого поля.
    // `:focus-within`, а не `:focus-visible`: у поля ввода фокус с клавиатуры и мышью
    // равнозначен, и в обоих случаях человек должен видеть, куда печатает.
    //
    // Индикатор намеренно тихий: акцентная рамка в 1px (4,73:1 на белом — выше
    // требуемых WCAG 1.4.11 3:1 для нетекстовых элементов) плюс мягкое кольцо
    // `accent-soft`. Прежний `outline: 2px solid accent` поверх той же рамки был
    // единственной кричащей деталью на всей панели.
    &:focus-within {
      border-color: tok-color(accent);
      box-shadow: 0 0 0 3px tok-color(accent-soft);
    }
```

### Задача 4: Авто-растущее поле ввода с Shift+Enter

Закрывает пункт 5 постановки.

**Файлы:**
- Создать: `src/tok/utils/autoGrow.js`

**Интерфейсы:**
- Потребляет: `.tok-composer__field` из задачи 3 (правится другой набор объявлений).
- Отдаёт:
  - `src/tok/utils/autoGrow.js` — `nextTextareaHeight(scrollHeight: number, min?: number, max?: number): number`, `isScrollable(scrollHeight: number, max?: number): boolean`, константы `COMPOSER_MIN_HEIGHT: number`, `COMPOSER_MAX_HEIGHT: number`.
  - `TokComposer` сохраняет публичные методы `focus()`, `setText(text: string)` и событие `send(text: string)` — на них завязаны `TokPanel.pickSuggestion` и голосовой ввод.

**Геометрия.** Поле: `padding: 6px 0`, `line-height: 20px` ⇒ одна строка = **32px** = `COMPOSER_MIN_HEIGHT`. Максимум **128px** ≈ 6 строк, дальше внутренний скролл. Контейнер: `padding: 6px`, кнопки 32px ⇒ базовая высота таблетки **44px** вместо нынешних ~52px.

**Почему отдельный модуль под три строки арифметики.** В jsdom `scrollHeight` всегда 0 — измерять высоту в тесте компонента бессмысленно. Вынесенная чистая функция проверяется честно, а на компоненте остаётся только то, что jsdom умеет: Enter отправляет, Shift+Enter — нет.

Создать `src/tok/utils/autoGrow.js`:

```js
/**
 * Высота авто-растущего поля ввода.
 *
 * Отдельный модуль, а не метод компонента: `scrollHeight` в jsdom всегда 0, и
 * проверить арифметику внутри компонента невозможно. Здесь она проверяется честно,
 * а компоненту остаётся только чтение DOM и присвоение стиля.
 *
 * Высоты в пикселях и связаны с вёрсткой: `line-height: 20px` плюс `padding: 6px`
 * сверху и снизу дают ровно 32px на одну строку. Менять одно без другого нельзя.
 */

/** Одна строка. Базовая высота поля, ниже которой оно не схлопывается. */
export const COMPOSER_MIN_HEIGHT = 32;

/** Примерно шесть строк. Дальше поле не растёт, а прокручивается внутри себя. */
export const COMPOSER_MAX_HEIGHT = 128;

/**
 * @param {number} scrollHeight — измеренная высота содержимого поля
 * @returns {number} высота, которую нужно выставить полю
 */
export function nextTextareaHeight(scrollHeight, min, max) {
  const floor = typeof min === 'number' ? min : COMPOSER_MIN_HEIGHT;
  const ceiling = typeof max === 'number' ? max : COMPOSER_MAX_HEIGHT;
  // Незамеренное поле (jsdom, скрытый контейнер) — это не «нулевая высота»,
  // а «нечего измерять»: отдаём базу, а не схлопнутую строку.
  const measured = Number.isFinite(scrollHeight) ? scrollHeight : 0;

  return Math.min(Math.max(measured, floor), ceiling);
}

/** Содержимое переросло потолок — поле обязано показать собственную прокрутку. */
export function isScrollable(scrollHeight, max) {
  const ceiling = typeof max === 'number' ? max : COMPOSER_MAX_HEIGHT;
  return Number.isFinite(scrollHeight) && scrollHeight > ceiling;
}

export default nextTextareaHeight;
```

<script>
/**
 * Подтверждение опасного действия — маленьким меню под кнопкой, которая его вызвала.
 *
 * Не системный `confirm()`: он блокирует страницу хоста, выглядит чужеродно и в
 * части окружений подавляется вовсе. И не полоса в ленте: она сдвигала переписку
 * вниз, то есть вопрос «вы уверены?» перекраивал контент, ради которого панель и
 * открывали.
 *
 * Кнопка-якорь приходит слотом `trigger` и живёт **внутри** корня компонента —
 * именно поэтому клик по ней не считается «кликом мимо» и работает как тумблер,
 * без единого `@click.stop`.
 */
export default {
  name: 'TokConfirmMenu',

  props: {
    open: {
      type: Boolean,
      required: true,
    },
    text: {
      type: String,
      required: true,
    },
    confirmLabel: {
      type: String,
      default: 'Очистить',
    },
    cancelLabel: {
      type: String,
      default: 'Отмена',
    },
  },

  watch: {
    open(isOpen) {
      return isOpen ? this.listen() : this.unlisten();
    },
  },

  mounted() {
    if (this.open) this.listen();
  },

  beforeDestroy() {
    // Меню может быть уничтожено открытым (закрыли панель) — слушатель на документе
    // обязан уйти вместе с ним.
    this.unlisten();
  },

  methods: {
    focus() {
      if (this.$refs.confirm) this.$refs.confirm.focus();
    },

    listen() {
      // `mousedown`, а не `click`: меню должно исчезнуть до того, как сработает
      // элемент под ним, иначе человек «проваливается» сквозь закрывающееся меню.
      document.addEventListener('mousedown', this.onOutside);
    },

    unlisten() {
      document.removeEventListener('mousedown', this.onOutside);
    },

    onOutside(event) {
      if (this.$el.contains(event.target)) return;
      this.$emit('cancel');
    },
  },
};
