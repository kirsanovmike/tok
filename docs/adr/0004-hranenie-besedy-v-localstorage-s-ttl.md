# ADR-0004. Беседа хранится в `localStorage` с TTL в один месяц

**Дата:** 2026-08-12
**Статус:** принято

## Контекст

Контракт возвращает `conversationId`, но не описывает, кто его хранит. Бэкенд хранения истории пока не предоставляет.

Исполнитель рекомендовал держать историю только в памяти на время сессии страницы: в переписке оказываются стоимость и объёмы по договорам конкретных юрлиц, а `localStorage` переживает закрытие браузера и доступен на общем компьютере.

Заказчик рассмотрел возражение и принял решение хранить в `localStorage`, отложив серверное хранение на будущее, и запросил TTL в один месяц.

## Решение

Переписка и `conversationId` сохраняются в `localStorage` под **версионированным ключом**.

Ограничения, снижающие риск:

- хранятся **только** сообщения и `conversationId` — никаких токенов;
- **TTL сообщения — один месяц**, просроченные удаляются при инициализации;
- кнопка «Очистить беседу» с подтверждением;
- сброс хранилища при смене пользователя;
- повреждённые или устаревшие по версии данные не роняют приложение — старт с пустой беседой.

## Последствия

- Переписка переживает перезагрузку страницы, чего заказчик и хотел.
- Коммерческие данные остаются на клиенте до месяца — принятый заказчиком риск, зафиксирован здесь явно.
- Версионированный ключ позволит сменить схему хранения без миграций.
- Переход на серверное хранение потребует замены только слоя хранилища.
