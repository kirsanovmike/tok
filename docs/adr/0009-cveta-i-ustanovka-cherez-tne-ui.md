# ADR-0009. Цвета и установка — через `@tne-ui`

**Дата:** 2026-08-24
**Статус:** частично отменено [ADR-0010](0010-stili-bez-kontrakta-tema-cherez-vuetify.md)
**Отменяет частично:** [ADR-0001](0001-otkaz-ot-tne-ui-v-polzu-vuetify.md)

> ADR-0010 снял отсюда SCSS-контракт (`tok-color()`, миксины, `$tok-*`) и
> `applyTokTheme`. В силе осталось всё про установку одним импортом и про имена
> переменных без суффикса `-base`.

## Контекст

ADR-0001 фиксировал: пакеты `@tne-ui/*` недоступны, строим на Vuetify, при
появлении доступа решение пересматривается. Доступ появился со стороны заказчика:
он сам положил цвета Тока в `@tne-ui/core` и подключил их в глобальный `styles.scss`
(`docs/Задача на доработку 1.md`).

Из этого следуют два расхождения с прежней реализацией.

1. Переменные объявлены **вручную** — `--v-tok-surface`, без суффикса `-base`.
   Суффикс дописывал парсер темы Vuetify 2 плоским цветам палитры; этого пути
   в новой схеме нет.
2. Компонент едет в `@tne-ui/components` и импортируется в лейауте, который
   тянется из библиотеки во все SPA. Плагину установки в такой схеме взяться
   неоткуда: лейаут импортирует компонент, а не настраивает конструктор Vue.

## Решение

- `tok-color($token)` возвращает `var(--v-tok-#{$token})`. Функции `host-color()`
  в компоненте нет: базовые цвета хоста ему не нужны, а демо-стенду она оставлена
  в `src/demo/styles/_host.scss`.
- Набор функций, миксинов и SCSS-переменных Тока живёт в `@tne-ui/core`; копия
  в `src/Tok/styles/_tokens.scss` держится байт в байт и нужна там, где core нет.
  Скругление шторки в контракт не входит — оно объявлено в `TokPanel.vue`.
- `installTok` удалён. `MountingPortal` регистрируется локально в `Tok.vue`.
  Импорт по умолчанию из `index.js` отдаёт сам компонент.
- `theme/tokens.js` остаётся источником истины по значениям цвета: из него
  красится amCharts (SVG из JS не понимает `var(…)`) и из него же
  `theme/applyTokTheme.js` раскладывает переменные там, где `@tne-ui/core` нет.
  Поверх объявлений библиотеки `applyTokTheme` не пишет.

## Последствия

- Ток больше не зависит от темы Vuetify вовсе. Vuetify остаётся зависимостью
  только демо-стенда.
- Значения цветов существуют в двух местах: в `@tne-ui/core` и в `theme/tokens.js`.
  Расхождение возможно и ловится только глазами — источником истины считается core,
  `tokens.js` правится следом.
- Схема установки у хоста упрощается до одной строки импорта; забыть шаг установки
  больше нельзя.
- Функции и миксины контракта должны быть в области видимости каждого SFC.
  В `@tne-ui` это обеспечено самой библиотекой; копия `styles/_tokens.scss`
  в папке нужна только там, где core нет.
